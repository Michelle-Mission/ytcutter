# YT Cutter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Android: paste URL YouTube, pilih resolusi, tandai detik awal–akhir, file terpotong masuk galeri.

**Architecture:** Satu modul Gradle, Compose M3, mesin `youtubedl-android` (yt-dlp + ffmpeg + Python 3.8). yt-dlp dipanggil serial lewat satu `Mutex` dari foreground service; UI hanya membaca state. File ditulis ke `cacheDir`, dipublikasikan ke MediaStore, lalu dihapus.

**Tech Stack:** Kotlin 2.4.21, AGP 8.13.2, Gradle 8.14.8, Compose BOM 2025.06.01, activity-compose 1.10.1, lifecycle 2.9.1, core-ktx 1.16.0, coil3 3.2.0, `io.github.junkfood02.youtubedl-android:{library,ffmpeg}:0.18.1`, JUnit 4.13.2.

**Spec:** `docs/superpowers/specs/2026-11-22-ytcutter-design.md`

## Global Constraints

- minSdk 29, compileSdk/targetSdk 36, `android:extractNativeLibs="true"`.
- Hanya `arm64-v8a`; `splits.abi` aktif. Jangan set `ndk.abiFilters` (konflik dengan splits).
- Paket `app.ytcutter`; proyek di `/ytcutter`; `sdk.dir=/opt/android-sdk`.
- Proses yt-dlp tidak boleh paralel (`Mutex`), satu unduhan aktif.
- Output hanya ke `Movies/YT Cutter` via MediaStore; temp di `cacheDir` dihapus di `finally`.
- Lisensi app: GPL-3.0.
- Tanpa DB, DI framework, Retrofit.
- Verifikasi perintah: `./gradlew testDebugUnitTest` untuk unit test, `./gradlew assembleDebug` untuk build.

## Review Focus

1. URL bukan YouTube / playlist → pesan jelas, tidak crash.
2. Rentang melewati durasi, `start >= end`, `end == duration` → clamp/validasi benar.
3. Judul beremoji / `%` / `/` → nama file aman, publish MediaStore sukses.
4. Challenge / cookies kedaluwarsa → pesan actionable, bukan stack trace.
5. Cancel saat ffmpeg berjalan / storage penuh → temp bersih, tak ada entry `IS_PENDING` nyangkut.
6. App background / layar mati → unduhan lanjut (foreground service).
